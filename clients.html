Do I need to purchase a course to start using Youwind?
No, the onboarding process is included in your subscription fee.
Does Youwind have any specific IT requirements?
No, however we recommend using Google Chrome.
How many users can work at the same time on one project?
Many users can work on the same project, as long as you save your changes for the rest to see the updates live.
Is it possible to define different user permissions?
Yes, you will be able to assign different Edit/Read permissions to the users based on their area of expertise.
